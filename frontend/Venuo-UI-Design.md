# Venuo UI Design System

> This document is the single source of truth for the Venuo frontend UI.
> Any new or modified UI must follow these rules unless a specific feature requirement overrides them.

---

# 1. Product Identity

## Product Name

Venuo

## Product Type

Venuo is a modern marketplace for discovering, listing, and booking different types of spaces.

Users can discover and book:

- Cafés
- Workspaces
- Coworking spaces
- Meeting rooms
- Auditoriums
- Event halls
- Studios
- Creative spaces
- Sports spaces
- Outdoor spaces
- Other bookable spaces

There are two primary user experiences:

### Booker / Guest

Discover → Search → Compare → Check availability → Book → Pay

### Space Owner / Host

List space → Publish → Receive bookings → Manage bookings → Manage calendar → View revenue

---

# 2. Overall Visual Direction

Venuo must look like a:

> Modern, warm, premium space marketplace.

It must NOT look like:

- A generic SaaS dashboard
- A hotel booking website
- A corporate ERP
- An overly colorful marketplace
- An overly rounded AI-generated interface

The visual language should be:

- Clean
- Warm
- Premium
- Spacious
- Modern
- Photography-driven
- Easy to scan
- Trustworthy

---

# 3. Brand Theme

## Theme Name

Venuo Warm Coral

The visual identity is based on:

- Warm neutral backgrounds
- Charcoal typography
- Coral brand accents
- White surfaces
- High-quality venue photography
- Generous whitespace
